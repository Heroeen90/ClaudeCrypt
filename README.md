## ✨ المميزات

- 🔐 **AES-256-GCM / CBC / ثلاثي الطبقات** — تشفير عسكري المستوى
- 🌊 **طبقة أصفار ريمان** — تشفير رياضي فريد
- 🖼️ **Steganography** — إخفاء رسائل داخل الصور
- ⏰ **الكبسولة الزمنية** — رسائل لا تُفتح قبل تاريخ محدد
- 🔬 **محلل الشفرات** — كشف وكسر الشفرات الكلاسيكية
- ⚡ **مولد مفاتيح متقدم** — عشوائي، ريمان، جيروسكوب، صورة
- 🔒 **قفل بالبصمة / PIN** — حماية بيومترية
- 💾 **حافظة آمنة** — لحفظ مفاتيح التشفير
- 📱 **PWA** — يعمل offline كتطبيق حقيقي
- 🌍 **مجاني 100%** — بدون تكلفة أو اشتراك
